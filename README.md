# TorrentCreator v2.3.0

TorrentCreator is a Windows application that creates BitTorrent v1 `.torrent` files and preview media from video files.

This release is fully translated into English and adds animated WebP preview support alongside GIF.

## Main features

- Sequential job queue for multiple videos. Jobs are always processed one at a time.
- Drag & drop support in the Windows build.
- Creates a BitTorrent v1 `.torrent` file.
- Creates 5 separate JPEG screenshots by default.
- Creates a 27-frame contact sheet using a 3 × 9 layout.
- Contact sheet width is 1300 px by default.
- The video filename remains clearly visible at the top of the contact sheet.
- Each contact-sheet frame includes a timestamp.
- Creates an animated preview from short segments between 20% and 90% of the video.
- Preview format can be **GIF**, **WebP**, or **GIF + WebP**.
- Default preview settings: 8 clips, 1.0 second per clip, 540 px wide, 8 FPS, maximum 7 MB per generated preview.
- Automatically reduces quality/resolution settings when needed to stay under the selected maximum size.
- Animated WebP usually provides better visual quality at a smaller file size than GIF.
- Lets you choose the output folder.
- Optional separate output subfolder for each video.
- Current-job progress and total-queue progress.
- Elapsed-time and estimated-time-remaining indicators.
- Cancel button for active processing.
- Processing modes: Everything, Torrent only, Screenshots/contact sheet only, or Animated preview only.
- Existing output files can be skipped or overwritten.
- Output verification after each job.
- Successfully completed jobs are removed from the queue automatically. Source videos and generated files are never deleted by this queue cleanup.
- Failed or cancelled jobs remain in the queue for review or retry.
- Settings are remembered between application sessions.

## Video Info & Tags

Select a queued video and click **Quick Check** to run an FFprobe analysis.

TorrentCreator can display:

- container format
- resolution
- duration
- total bitrate
- video codec and profile
- frame rate
- pixel format
- HDR information when reported by FFprobe
- audio tracks, codecs, channel layouts, languages, and track titles
- subtitle tracks, languages, and track titles
- chapters and chapter start times
- embedded metadata tags from the container and individual streams
- common release tags detected in the filename, such as 720p, 1080p, 2160p, WEB-DL, WEBRip, BluRay, REMUX, x264/H.264, x265/HEVC, AV1, HDR, HDR10, HDR10+, Dolby Vision, 10-bit, TrueHD, Atmos, DTS, DTS-HD, DTS:X, DD+/E-AC-3, AC-3, AAC, and FLAC

Filename tags are shown separately from the actual technical properties of the video. A filename containing `x265`, for example, does not automatically mean the video stream is actually HEVC.

## Privacy mode

Privacy mode is enabled by default.

It removes optional metadata generated by TorrentCreator, including:

- `created by` from the `.torrent` file
- optional torrent creation date
- torrent comment
- EXIF metadata from generated JPEG files
- transferred metadata from generated GIF/WebP files

The filename is intentionally preserved in the torrent and remains visible on the contact sheet.

The privacy checker also flags selected embedded metadata fields that may reveal information such as author/artist, comments, encoder, creation time, location/GPS, copyright, email addresses, or phone numbers.

Important: TorrentCreator never modifies the original video. Any metadata already embedded in the original video remains in that original file.

## Default media settings

- Separate screenshots: 5
- Contact sheet: 3 columns × 9 rows
- Contact sheet width: 1300 px
- Margin: 5 px
- JPEG quality: 80
- Screenshot range: 10% to 90%
- Animated preview format: GIF by default (WebP or GIF + WebP can be selected)
- Preview range: 20% to 90%
- Preview clips: 8
- Seconds per preview clip: 1.0
- Preview width: 540 px
- Preview frame rate: 8 FPS
- Maximum size: 7 MB per preview

## Animated WebP support

The **Animated Preview** tab now contains a **Preview format** selector:

- **GIF** – creates only `*_preview.gif`
- **WebP** – creates only `*_preview.webp`
- **GIF + WebP** – creates both formats sequentially

The same clip range, number of clips, seconds per clip, width, frame rate, and maximum file-size setting are used for both formats. When **GIF + WebP** is selected, the maximum size applies separately to each output file.

WebP encoding is handled by the bundled FFmpeg build through `libwebp_anim`; no extra WebP software is required.

## Build the Windows EXE

On Windows:

1. Extract this Build Kit.
2. If you already have a `.build-tools\ffmpeg` folder from an older version, copy it into the same location in this version to avoid downloading FFmpeg again.
3. Double-click `BUILD_WINDOWS_EXE.bat`.
4. Wait for the build to finish.
5. Launch the finished application from:

```text
dist-windows\single\TorrentCreator.exe
```

Do not run an EXE from `build-windows`. That folder contains temporary PyInstaller build files only.

The finished Windows EXE bundles FFmpeg and FFprobe, so the end user does not need to install Python, Pillow, tkinterdnd2, or FFmpeg separately.

## Portable folder build

Run `BUILD_PORTABLE.bat` to create a portable folder/ZIP build. The result is placed under:

```text
dist-windows\portable\
```

## Run the Python version directly

```text
pip install -r requirements.txt
python torrent_creator.py
```

When running the Python source directly, `ffmpeg` and `ffprobe` must be available in PATH or placed next to the application.

## Output structure

Choose an **Output folder** before starting the queue. With **Separate subfolder for each video** enabled, a typical result looks like this:

```text
D:\TorrentOutput\MyVideo\
    MyVideo.torrent
    MyVideo_screenshot_01.jpg
    MyVideo_screenshot_02.jpg
    MyVideo_screenshot_03.jpg
    MyVideo_screenshot_04.jpg
    MyVideo_screenshot_05.jpg
    MyVideo_layout_3x9.jpg
    MyVideo_preview.gif
    MyVideo_preview.webp   (when WebP or GIF + WebP is selected)
```

For folder-based torrents, the output folder must be outside the source folder so previously generated media files are not accidentally included in the torrent.

## Regenerate only one part

Open the **Processing** tab and choose **Animated preview only**. In the **Animated Preview** tab, choose **GIF**, **WebP**, or **GIF + WebP**. Enable **Overwrite existing files** if you want to recreate an existing preview.

When overwrite is disabled, TorrentCreator skips files that already exist and continues with missing output files.

## Saved settings

On Windows, application settings are normally stored in:

```text
%APPDATA%\TorrentCreator\settings.json
```

Only application settings are stored there. Video files are not copied there.

## Windows SmartScreen

TorrentCreator is locally built and is not digitally code-signed. Windows SmartScreen may therefore display a warning the first time the EXE is launched. The Python source code is included as `torrent_creator.py`.
